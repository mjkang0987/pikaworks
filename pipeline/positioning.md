## 한 줄

**내가 못 고치는 페이지의 링크도, 제목과 이미지가 뜨게.**

## 포지셔닝 문장

> 네이버 블로그·스마트스토어·인스타처럼 **HTML 을 손댈 수 없는 페이지**를 공유하는 사람에게,
> ClipNote 는 붙여넣기 한 번으로 **제목과 대표 이미지가 뜨는 공유 카드**를 만들어 주는 도구다.
> 그 페이지의 메타데이터를 대신 읽어오고, 안 잡히는 사이트는 전용 어댑터로 처리하기 때문이다.

## 카테고리

**단축링크가 아니라 "공유 카드"다.** 이 구분을 흐리지 않는다.

- 단축링크 카테고리는 2024-10 네이버 me2.do 가 **피싱 때문에** 종료하면서 "수상한 링크" 낙인이 찍혔다
- 우리가 파는 건 주소를 줄이는 게 아니라 **받는 사람이 뭔지 알아보게 하는 것**이다
- 서비스 문구도 이미 그렇게 잡혀 있다 — `meta.siteTitle` = "ClipNote — URL을 깔끔한 공유 카드로"

## 타겟

**1순위 — 링크를 내보내는 사람.** 공동구매 셀러, 블로그마켓, 학원, 병원, 공방, 1인 사업자.
네이버 블로그·스마트스토어·인스타로 장사하는 사람들이다.

왜 이 사람들인가:

- **HTML 에 손을 못 댄다.** 세상의 모든 OG 가이드는 "내 페이지에 메타태그를 넣어라"를 전제한다.
  이 사람들은 그 전제 밖에 있다
- **수요가 실재한다.** 카페24·아임웹·캠페이너스가 "카톡 썸네일 안 바뀜" FAQ 를 운영한다.
  호스팅사가 FAQ 를 쓴다는 건 문의가 반복된다는 뜻이다
- **경쟁사 헤드라인이 이들에게 안 읽힌다.** Edgelink 는 "인앱 브라우저 Google 로그인 우회",
  비볼디는 "클릭 데이터 실시간 확인" — 개발자·퍼포먼스 마케터 언어다

**2순위 — 카톡으로 링크 보내는 일반 사용자.** 시장은 크지만 의도가 약하다. 1순위를 흐리지 않는 선에서만 다룬다.

**타겟 아님 — 링크를 모으는 사람.** 딸깍·Catch Link·Stash 가 있는 자리다.
저장(input) 앱과 싸우지 않는다. 우리는 내보내는(output) 쪽이다.

## 차별점 셋 — 전부 코드로 확인됨

| | 우리 | 근거 |
|---|---|---|
| **남의 페이지도 된다** | 네이버 카페·인스타 전용 어댑터, 크롤러 UA·브라우저 UA 2회 시도, 차단 페이지는 제목을 비운다 | `lib/metadata.ts`, `lib/adapters/*` |
| **캐시에 안 막힌다** | 슬러그가 매번 새로 생성돼 항상 새 URL 이다. 카카오가 캐시할 이전 값이 없다 | `lib/slug.ts` — 랜덤 7자 base-57 |
| **로그인 없이 확인, 무료** | 붙여넣으면 카드 미리보기가 바로 뜬다. 짧은 링크만 로그인 | `compare.guestItem1`, FAQ `a6` |

**캐시가 핵심이다.** 검색 상위 질문은 "OG 설정법"이 아니라 **"바꿨는데 안 바뀐다"** 다.
기존 해법은 전부 "카카오에 캐시 삭제를 요청하세요" — 남에게 의존하는 답이다.
우리는 구조적으로 그 문제를 안 만든다. **이 각도를 말하는 경쟁사가 없다.**

## 안 하는 말

- **"단축링크"** — 피싱 낙인이 있는 카테고리로 스스로 걸어 들어가지 않는다
- **"무료"를 헤드라인으로** — 기능 가치가 묻힌다. 본문에서 언급한다
- **경쟁사 이름** — 사업자 등록 전이라 분쟁 리스크를 안 진다
- **추적·분석 소구** — 우리는 그 기능이 없다. Edgelink·비볼디의 자리다
- **"OG 태그"·"오픈그래프" 같은 개발자 용어를 제목에** — 타겟이 쓰는 말은
  "카톡 썸네일", "미리보기 안 떠요", "링크 보내면 회색 네모"다

## 콘텐츠 축 4개

매일 랜덤으로 기능을 고르지 않는다. 아래 축에서 돌린다.

| 축 | 무엇 | 누구에게 |
|---|---|---|
| **1. 카톡 미리보기 문제** | 왜 안 뜨나 · 왜 안 바뀌나(캐시) · 어떤 링크가 특히 안 되나 | 검색으로 오는 사람 |
| **2. 내 사이트가 아닌 링크** | 네이버 블로그·스마트스토어·카페·인스타 링크 공유 | 1순위 타겟 |
| **3. 링크로 장사하는 사람** | 공구 셀러·학원·병원·공방의 실제 공유 장면 | 1순위 타겟 |
| **4. 받는 사람** | 뭔지 알아보는 링크 · 안 눌리는 링크 | 신뢰 각도 |

**한 게시물은 한 축에만 속한다.** 5개를 뽑을 때 최소 3개 축이 섞이게 한다.

## 전환 경로

```
게시물 → 프로필 링크 → clipnote.co.kr → 로그인 없이 즉시 체험 → (필요해지면) 로그인
```

**"로그인 없이 즉시 체험"이 이 경로의 핵심 자산이다.** 붙여넣기만 하면 카드가 바로 뜬다.
게시물 CTA 는 설치·가입을 요구하지 말고 **"주소 하나 붙여넣어 보세요"** 로 간다.

## 위협

- **브랜드명 검색이 죽어 있다.** "클립노트"로 검색하면 KT 클립카드·클립아트코리아·동명의
  안드로이드 앱이 나온다. 이름으로는 못 찾는다 → **문제 키워드로 들어오게 해야 한다(축 1)**
- **FINGERPUSH.LINK** 가 커스텀 OG 를 정면으로 소구하고 무료 플랜에서도 제공한다. 가장 직접적인 경쟁
- **Edgelink** 가 `kakao-link-preview-fix` 로 축 1의 검색 자리를 이미 잡았다
- 국내 유료 단축링크는 월 2~9만원, Edgelink 는 3,900~9,900원. **우리는 무료지만 수익 모델이 없다**

## 확인 안 된 것

- ClipNote 자체 유입·설치·리텐션 수치 (서치 콘솔·인사이트 접근 없음)
- 대표 이미지 직접 교체가 UI 에 노출되는지 (`POST /api/clip` 은 `image` 를 받지만 화면 확인 못 함)
- 네이버 카페·블로그의 정량적 검색량 (검색 도구가 네이버 색인 미포함)
- 1순위 타겟이 실제로 이 문제로 돈을 잃는다는 증거 (정황만 있고 인터뷰·설문 없음)
